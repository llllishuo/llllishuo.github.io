我是 **MenghanStudio**，做嵌入式和系统方向的事情：写过 RTOS 上的驱动，也用 Rust 跟着教程从零写过一个操作系统内核，笔面试时把 C++ / Rust / RTOS 的知识点整理成了几份笔记。

这个站点是那些东西的落脚处。

## 这里有什么

- **[开发笔记](/categories/dev/)** —— 踩过的坑、想明白的原理。比如内核怎么访问页表这种一开始完全绕不过去的问题。
- **[笔面试](/categories/interview/)** —— C++ / Rust / RTOS 的题目和自己的答案，边准备边补。
- **[读书笔记](/categories/reading/)** —— 马列毛经典原著的摘录与批注。读原著比读二手解读慢，但能看清论证本身。
- **[专题](/categories/special/)** —— 长线整理的题目，一次串一条线索。

## 做过的东西

- **[FuckOff](/projects/fuckoff/)** —— Android 黑名单应用清理器。把你主动拉黑的 App 请出手机，纯本地运行，没有网络权限。
- **[时薪计算器](/projects/hourlywage/)** —— 三端（Windows / 网页 / 终端）同一套公式和进位规则的时薪计算工具，结果逐条比对一致。

## 关于这个站

站点是静态页面：文章写在 `content/posts/` 里，用 Python 脚本（[build.py](https://github.com/llllishuo/llllishuo.github.io/blob/main/build.py)）生成，托管在 GitHub Pages 上。没有前端框架，没有第三方 CDN，也不需要登录和追踪脚本。

内容仅作学习交流。有疑问或者发现错误，欢迎通过邮件或者 GitHub Issue 告诉我。
